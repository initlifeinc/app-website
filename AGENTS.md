# Product site guidance

- Publishable files live at the repository root. Preserve directly accessible homepage, Blog, article, privacy, terms and 404 routes.
- Keep confirmed product copy and real App screenshots accurate; no fictional users, ratings or claims.
- Mount shared navigation via `assets/site.js` and `[data-site-header]`.
- Keep contact labels personal: 给我留言 / Leave me a message.
- Retain ICP and public security filing links together with copyright in the footer.
- Domain: app.initlife.com; GitHub Pages publishes main at /. Keep CNAME and .nojekyll.
- Never commit credentials or private user data. Preview and check links, assets and language switching before publication.
